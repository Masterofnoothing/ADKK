# Project Overview

This Computer Graphics for Robotics lab project features a fully modeled, textured, and rendered **4-legged exploratory robot** designed for rugged extraterrestrial terrain.

![Four-legged explorer robot](images/cgr-4legged-robot.jpg)

---

# Geometry & Construction

The model uses a hierarchical structure:

1. **Base Hub:** Central pod for sensors, power cores, and antenna rigs.
2. **Hip Joint:** Spherical joint permitting multi-axis rotation.
3. **Upper and Lower Limbs:** Intersecting piston-driven beams.
4. **Footpad:** Cushioning pad for ground impacts.

### Rendering Settings

The project used Eevee for iteration and Cycles for final renders, with a 50mm lens and studio HDRI lighting.
